# Bible visuelle

## Intention

La série doit conserver une identité immédiatement reconnaissable : forêt colorée, ambiance chaleureuse, personnages adorables, formes douces et expressions très lisibles.

Cette bible sert de référence avant toute création d’image, d’asset ou d’animation.

## Direction générale

- Esthétique familiale et chaleureuse.
- Couleurs riches et naturelles.
- Contraste suffisant pour séparer les personnages du décor.
- Formes arrondies et silhouettes simples.
- Expressions faciales lisibles à petite taille.
- Lumière douce, avec une variation claire entre matin, journée, fin d’après-midi et scènes de suspense.

## Palette

La palette définitive doit rester alignée sur l’image de référence fournie pour le projet. Les couleurs principales doivent être documentées une fois les assets maîtres validés.

Familles de couleurs à préserver :
- verts de végétation ;
- bruns chauds du bois et des animaux ;
- couleurs naturelles des sols ;
- accents lumineux pour les fleurs, fruits et éléments narratifs.

## Environnements

La forêt doit donner l’impression d’un lieu vivant et cohérent.

Éléments récurrents :
- arbres ;
- feuillages ;
- rochers ;
- petits chemins ;
- clairières ;
- ruisseau ou zone humide selon les épisodes ;
- terriers et abris.

Les arrière-plans ne doivent pas voler l’attention aux personnages pendant les dialogues.

## Caméra

Privilégier :
- plans moyens pour les dialogues ;
- plans larges pour situer l’action ;
- gros plans pour les émotions ou indices ;
- mouvements de caméra simples et motivés.

Éviter les mouvements trop rapides ou complexes dans les scènes destinées aux jeunes enfants.

## Lumière et suspense

Le suspense est créé par :
- le silence ;
- un changement de cadrage ;
- un bruit hors champ ;
- une ombre ;
- une réaction des héros.

Éviter toute représentation graphique de violence.

## Référence image

L’image fournie par le créateur constitue la référence artistique initiale. Toute nouvelle génération d’image doit viser une continuité de :
- proportions ;
- texture ;
- niveau de détail ;
- traitement des yeux et du visage ;
- lumière ;
- ambiance de forêt.

## Contrôle qualité visuel

Avant validation d’un asset, vérifier :
- silhouette ;
- couleurs ;
- proportions ;
- expressions ;
- cohérence avec les autres personnages ;
- absence d’éléments parasites ;
- lisibilité en petit format.
