# Workflow de production

## 1. Préproduction

### Concept
Définir :
- thème ;
- message ;
- conflit ;
- résolution ;
- personnages présents.

### Scénario
Le scénario doit préciser les actions, dialogues et transitions.

### Storyboard
Chaque séquence reçoit un numéro, un timecode, un cadrage et une intention sonore.

## 2. Assets

Créer et valider les assets maîtres avant animation :
- personnages ;
- expressions ;
- poses ;
- décors ;
- accessoires ;
- éléments de végétation ;
- effets simples.

Les fichiers de référence doivent être versionnés et ne pas être remplacés silencieusement.

## 3. Animation

Ordre recommandé :
1. animatique ;
2. blocage ;
3. mouvements principaux ;
4. expressions ;
5. secondaires ;
6. effets ;
7. nettoyage.

## 4. Voix

Enregistrer les dialogues avant le montage final afin d’ajuster les mouvements de bouche et le timing.

Contrôles :
- intelligibilité ;
- niveau homogène ;
- absence de bruit parasite ;
- rythme adapté aux enfants.

## 5. Sound design

Construire trois couches :
- ambiance de forêt ;
- effets narratifs ;
- musique.

Le silence peut être utilisé comme outil de suspense.

## 6. Montage

Valider successivement :
- rythme ;
- compréhension ;
- continuité ;
- durée ;
- lisibilité des dialogues ;
- équilibre musique / voix / effets.

## 7. Contrôle qualité

### Narratif
- L’objectif de la scène est clair.
- Aucun événement n’est contradictoire.
- La résolution est compréhensible.

### Visuel
- Designs cohérents.
- Pas de variation accidentelle des personnages.
- Pas d’artefacts.
- Pas de texte parasite.

### Audio
- Voix compréhensible.
- Pas de clipping.
- Musique sous contrôle.
- Transitions propres.

## 8. Exports

Conserver :
- master haute qualité ;
- version YouTube ;
- version verticale ;
- miniature ;
- sous-titres ;
- métadonnées.

Les paramètres techniques définitifs doivent être documentés dans la version de production utilisée.

## 9. Publication

Avant publication :
- vérifier titre et description ;
- vérifier miniature ;
- vérifier sous-titres ;
- vérifier classification et paramètres destinés au jeune public ;
- vérifier les droits des musiques, voix, images et autres ressources.

## 10. Versionnement

Utiliser des commits courts et explicites :

```
feat: nouvelle scène
docs: mise à jour storyboard
style: ajustement bible visuelle
fix: correction continuité
assets: ajout personnage
```

Le dépôt GitHub reste la source de vérité documentaire du projet.
